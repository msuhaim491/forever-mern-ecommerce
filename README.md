# FOREVER — Premium MERN E-commerce

An independent, portfolio-focused e-commerce application built with **React, Node.js, Express, MongoDB, and Stripe Checkout (test mode)**.

> **Status:** Source publication in progress. This is a learning project, not a verified production deployment. The store, admin panel, and payment flows still require live end-to-end validation.

## Planned showcase

- Responsive fashion storefront, product filtering, size selection and cart
- Customer sign-up/sign-in, COD checkout and order history
- Separate admin dashboard for products and orders
- MongoDB-backed API, JWT authentication and Stripe Checkout
- Accessible motion and mobile-friendly UI
